# こたつサーバー in GitHub

RealTrainModをメインに様々な活動を行っている非公開のサーバー、「こたつ」のGitHub組織です。  
「こたつ」では各メンバーが知的好奇心に突き動かされ、自由に活動しています。  
ここでは主にRealTrainMod関連の開発や、成果物の公開をしています。

## 公開されているモデルパック・ソースコード等の利用

- 各プロジェクトには原則README.mdとLICENSEの両ファイルが用意されています。  
  上記をご確認いただき、記載されている規約・許諾の範囲でご自由にお使いください。

- 一部のプロジェクトは、組織外に権利者がいるプロジェクトの派生やモデルパックの改変を含みます。  
  そのようなプロジェクトではREADME.mdにて各種案内をしておりますので、そちらもご参照ください。

- 本組織では、バグ修正・新機能・改善提案などについて、組織外からのIssueの起票やPull Requestの提出を歓迎しております。  
  その際には、通常の開発と同じく、内容の精査や修正依頼等をお願いすることがありますので、ご協力ください。  
  また、プロジェクトの方針に沿わない場合はお断りすることもありますので、ご理解のほどお願いいたします。

## お願い

- この組織は所属するメンバーによる任意の活動によって運営されています。  
  組織やメンバーに関する虚偽の発言や強要等はおやめください。  
  組織の維持のため、相応の対応をしなければならなくなる場合もあります。

- 組織外からのご意見やご要望にも対応したいという思いはありますが、対応が遅くなってしまったり、
  全てに対応できないこともあります。

- 各プロジェクトや組織について質問がありましたら、[連絡先](#連絡先)までお願いします。

## 連絡先

お手数ですが、各プロジェクトに関する質問は、プロジェクトのリポジトリにてIssueの起票をお願いいたします。

プロジェクトに関連しない問い合わせやセンシティブな内容につきましては、
`contact@kotatsu.tech`へメールをご送信ください(メールは組織の全メンバーが閲覧可能です)。
